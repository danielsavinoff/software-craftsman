## FAQ

### What problem does the skill solve?

You want clean code, but short prompts leave room for wrong assumptions. This skill makes the conventions explicit.

### Why does it exist?

Details are easy to leave out: what seems obvious to you may not be obvious to an agent. I was tired of repeating decisions I'd already made in previous projects.

### How was it built?

Each time an agent drifted from the result I wanted, I added a rule. The skill is opinionated, but I aim to make it the best it can be and welcome pull requests with a clear rationale.
